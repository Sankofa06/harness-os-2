# Implementation Plan

## Milestone 0 — scaffolding
Monorepo, Python package, web package, CI, formatting, typed clients.

## Milestone 1 — kernel
IDs, schemas, config, SQLite, migrations, events, jobs, auth, secrets abstraction.

## Milestone 2 — control plane
capability registry, settings-schema system, provider registry, host registry.

## Milestone 3 — language compute
generic OpenAI-compatible + LM Studio + Ollama + cloud adapters.

## Milestone 4 — execution
SSH hosts, safe workspaces, shell/file/git tools, artifact transfer.

## Milestone 5 — agent runtime
Contact/Role/Persona, context compiler, sessions, run loop, delegation, teams, permissions.

## Milestone 6 — MCP/skills
lazy indexes and activations.

## Milestone 7 — creative
Stability Matrix discovery/catalog, ComfyUI, compatible WebUI adapters, creative profiles, jobs, provenance.

## Milestone 8 — telemetry/analytics
runs, model metrics, host metrics, benchmark engine.

## Milestone 9 — node
optional daemon + pairing + telemetry.

## Milestone 10 — UI concurrently
TUI and WebUI against OpenAPI/event stream. Feature parity on core workflows.

## Milestone 11 — remote/mobile polish
responsive iPhone layouts, HTTPS/Tailscale docs, connection setup.

## Milestone 12 — release
demo fixtures, screenshot automation, docs, site, marketing, full audit.
