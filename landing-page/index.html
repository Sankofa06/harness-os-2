Archive roadmap

This path is complete because it continued elsewhere.

  1. Built

    Specification kit authored

    A coherent, inspectable product and engineering contract for a local-first agent and AI compute control plane.

  2. Resolved

    One-shot implementation created

    The specification was carried into the full Harness OS repository, where the source, tests, WebUI, TUI, CI, and project site now live.

  3. Decision

    Keep as history or archive it

    Retain this repository if the original handoff artifact is useful for provenance. Otherwise, GitHub's archive setting can make its superseded status unmistakable.

  4. Later

    No parallel feature track

    All implementation, validation, issues, and roadmap work belong in Harness OS. This repository should not diverge into a competing product.
